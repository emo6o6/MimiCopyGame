# コード耳

ギターのコードを聴いて、鍵盤でルートや構成音を探す耳コピ練習です。

出題はメジャー、マイナー、サスフォー、サスツー、ディミニッシュ、オーグメント、セブンス、マイナーセブンス、メジャーセブンスから選べます。答えたあと、正解か、半音いくつ高いか低いかを返します。

## 開き方

```bash
python3 -m http.server 8765
```

ブラウザで http://127.0.0.1:8765 を開きます。

## 練習のしかた

- **当てる音:** ルートだけ、または構成音すべて
- **かんたん:** 一音ずつ鳴ってからコードが鳴る。種類と音名が見える
- **ふつう:** コードが鳴る。音名は見える。一音ずつも聴ける
- **むずかしい:** コードが鳴るだけ。音名は隠れる

鍵盤を鳴らして高さを探し、「この音をルートにする」か「この音を追加」で答えを入れてから「答える」。パソコンでは A の列がド、黒鍵は W E T Y U です。

## テスト

```bash
node --test theory.test.mjs
```
